I am frontend developer working mainly in ReactJS with TypeScript React Router, Redux etc.
Since 2014 I worked for couple companies creating Single Page Applications, mainly for internal use.
Portfolio pages usually are show off with lots of colors, nice graphic and scroll features. Although in my opinion anybody can ask AI to create colorful image that catches the eye, and put it on a page. What's it telling about that person? That it has an eye to modern or classical design? What about its ability to create reliable code or organization in the project?
This pages sourcecode is available on my GitHub, and you can see:
  • how I structured the project,
  • configured the environment,
  • what React features I use (for now I have not used Redux in it yet),
  • styling ways for pages and components,
  • how I handled translations, routing etc.
You can also see implementations of some custom components that I could use from a library, but managed to code myself in TS
By developing those features myself I develop my skills and knowledge, but also save space, as most libraries available, are pulling lots of redundant code. Using my approach, I was able to downsize the amount of data transferred over the wire from over 10 MB to 1.14 MB in an application used in South Africans schools, where speed of the Internet is very limited.
But from the feedback, not only the time to load a test was improved. Also, the reliability was much better, as the app did not need to load so much data between tests, and reused lots of locally cached files, stored the test results locally, to try sending it again in case of Internet blackouts. Thanks to that, student's did not have to travel to the school again to take the same test again.
